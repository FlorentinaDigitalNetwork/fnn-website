Pentru programatori — catalogul JSON

Pasul 1: Deschide catalogul public MLCNA. Vei vedea date în format JSON, în limba română.

Pasul 2: Citește câmpul activitati pentru cele 100 de activități și câmpul verdicturi pentru motive și condiții.

Pasul 3: Alege aleatoriu o activitate, un verdict, un motiv și o condiție în programul tău. Aceasta este aceeași metodă folosită de pagina FNN.

Important: este un catalog JSON static, nu un API dinamic. Solicitările repetate la aceeași adresă primesc același catalog; generarea aleatorie se face în aplicația ta. Nu este nevoie de cheie API.

Adresă publică: https://fnn.gnica430.workers.dev/api/mlcna.json

Exemplu JavaScript

const r = await fetch('https://fnn.gnica430.workers.dev/api/mlcna.json');
if (!r.ok) throw new Error('HTTP ' + r.status);
const data = await r.json();
const random = a => a[Math.floor(Math.random() * a.length)];
const act = random(data.activitati);
const verdict = random(data.verdicturi);
console.log(act.activitate, verdict.cod, random(verdict.motive));

Exemplu Python

import json, random, urllib.request
url = 'https://fnn.gnica430.workers.dev/api/mlcna.json'
with urllib.request.urlopen(url, timeout=10) as r:
    data = json.load(r)
act = random.choice(data['activitati'])
verdict = random.choice(data['verdicturi'])
print(act['activitate'], verdict['cod'])
print(random.choice(verdict['motive']))

Programatorii care folosesc AutoHotkey v2 pot descărca JSON-ul cu WinHttp.WinHttpRequest.5.1 și îl pot parsa cu o bibliotecă JSON compatibilă cu AHK v2. Textul este UTF-8 și conține diacritice.
